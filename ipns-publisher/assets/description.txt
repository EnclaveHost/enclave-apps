Publish an IPNS name whose ed25519 key never leaves the enclave. The key is held in attestation instead of a plaintext file on disk; every record is signed inside the TEE and pushed out three ways: served directly on the delegated-routing HTTP surface (/routing/v1/ipns/<name>), PUT to delegated-routing endpoints, and stored on the public IPFS DHT by a hand-rolled, outbound-only libp2p stack (TCP + Noise XX + yamux + Kademlia PUT_VALUE) — no rust-libp2p, which does not target wasip2. Records are byte-for-byte kubo-compatible and pass ipfs name inspect; an independent node with an empty cache resolves the name straight from the DHT, trusting neither this app nor any gateway. The sequence stays strictly monotonic across restarts by recovering the last record from a durable volume, from the delegates, or from the DHT itself, so a fresh deploy never bricks the name. CPU-only, single-threaded, one loopback port; the only secret is the name key.
