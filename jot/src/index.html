  jot stores each note as one plain object under a prefix in your S3-compatible bucket (R2, S3, Wasabi, minio), written with SigV4 from inside the enclave.
  The App Config names the bucket; the S3 credentials and the API key are deployment secrets that exist only in the attested guest.
  The bucket stays readable with ordinary S3 tools, so a notebook that must be unreadable at rest belongs on an encrypted volume instead (see keep).
  Verify the enclave before trusting it: enclave.host.
