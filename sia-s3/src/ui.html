Any S3 client works: SigV4, ranges, copy, multipart, ListObjectsV2. The access keys are this deployment's S3_ACCESS_KEY_ID and S3_SECRET_ACCESS_KEY secrets. 

      

    

  


  

    Objects are encrypted and erasure-coded inside the enclave and spread across independent Sia hosts:
    any 10 of 30 shards rebuild an object, so no host can read the data and losing hosts loses nothing.
    The key index lives in the objects' own sealed metadata, so the app keeps no local state.
