Turn any HTTP API into an MCP server, served from an attested enclave. Describe endpoints in the app config exactly as an eyesoff-ai tools.http block does: a name, a description, JSON-Schema parameters, a URL with {arg} placeholders, a body template with $arg holes, and headers that reference $SECRET deployment secrets. Every MCP tools/call becomes one templated request the enclave makes with its own credentials, so the API keys never leave the attested guest and a caller chooses arguments, never a URL or a header. One streamable-HTTP endpoint then serves eyesoff-ai (one mcp entry replaces the whole block, with the same switches, pictures in and out, and the signed-in user forwarded), Claude Code, Cursor, and any other MCP client with the same key. Stateless and handshake-optional, so a client that skips initialize pays one round trip per call.
