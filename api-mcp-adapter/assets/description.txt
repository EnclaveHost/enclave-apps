Turn any HTTP API into an MCP server, served from an attested enclave. Endpoints live in the app config, their API keys as deployment secrets, so a key never leaves the guest. Every tool call is one request the enclave makes with the arguments the caller chose, and the caller never picks the host or a header, so it cannot become an open fetcher on your egress. One endpoint then serves every agent that speaks MCP. For eyesoff-ai it replaces the whole tools block with one entry, and nothing is lost crossing over: the same switches, pictures both ways, citations, the signed-in user. Stateless, handshake optional, one round trip per call.
