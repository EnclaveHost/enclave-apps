namesizecid
CIDs are computed exactly as ipfs add --cid-version 1 would (256 KiB chunks, raw leaves, balanced DAG), so they can be verified, pinned, or fetched anywhere. Every served byte is re-hashed against the index before it leaves the enclave. /ipfs/<cid> supports ?format=raw and ?format=car (trustless gateway) and HTTP ranges.
