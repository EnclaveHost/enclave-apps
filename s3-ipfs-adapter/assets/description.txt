Turn any S3-compatible bucket into IPFS content, served from an attested enclave. Every object gets the exact CID ipfs add would mint, and the bucket gets one root CID: a verifiable commitment you can pin, share, or cross-check anywhere without trusting this gateway. Bytes stay in your bucket; the enclave holds only the merkle index and re-hashes everything it serves, so changed data can never hide under a valid CID. Standard gateway surface: /ipfs paths, raw blocks, CAR streams, HTTP ranges, plus a UI with per-file CIDs. Works with AWS, R2, or minio, signed (SigV4) or public, and re-indexes changed objects automatically.
